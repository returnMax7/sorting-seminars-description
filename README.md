Алгоритмы сортировки — семинары 1–4

Учебное решение на C++20 для Visual Studio. Алгоритмы поддерживают int и double.

## Состав решения

- sem1: вставки, выбор, простой обмен, пузырьковая и улучшенная пузырьковая сортировки.
- sem2: бинарные вставки и шейкерная сортировка.
- sem3: быстрая сортировка и сортировка Шелла.
- sem4: двухфазное простое слияние, однофазное простое слияние и естественное слияние через временные файлы.
