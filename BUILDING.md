# Алгоритмы сортировки — семинары 1–4

Учебное решение на C++20 для Visual Studio. Алгоритмы поддерживают int и double.

## Состав решения

- sem1: вставки, выбор, простой обмен, пузырьковая и улучшенная пузырьковая сортировки.
- sem2: бинарные вставки и шейкерная сортировка.
- sem3: быстрая сортировка и сортировка Шелла.
- sem4: двухфазное простое слияние, однофазное простое слияние и естественное слияние через временные файлы.
- SortingTests: общие тесты Catch2 через макросы, включая индивидуальный вариант 15: 13, 9, 4, 16, 1, 11, 5, 20.

## Подготовка

Нужны Visual Studio с рабочей нагрузкой «Разработка классических приложений на C++», набором инструментов v145 и Windows SDK, а также Git и отдельная установка vcpkg.

В PowerShell, в выбранной папке для инструментов:

```powershell
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg.exe install catch2:x64-windows
.\vcpkg.exe integrate install
```

После интеграции перезапустите Visual Studio. Catch2 устанавливается отдельно, его исходники в репозиторий не включены.

## Сборка и тесты

1. Откройте Sorting.slnx в Visual Studio.
2. Выберите Debug / x64.
3. Назначьте SortingTests запускаемым проектом.
4. Соберите решение (Ctrl + Shift + B).
5. Запустите тесты (Ctrl + F5).

Проверенный результат: 5886 проверок в 69 тестах.

В Developer PowerShell for Visual Studio можно выполнить:

```powershell
msbuild Sorting.slnx /p:Configuration=Debug /p:Platform=x64
.\bin\x64\Debug\SortingTests.exe
```

Выборочный запуск:

```powershell
.\bin\x64\Debug\SortingTests.exe "[external]"
.\bin\x64\Debug\SortingTests.exe "[individual]"
```

## Файловые сортировки

Основной файл содержит числа, разделённые пробельными символами. Сортировка изменяет его на месте, используя вспомогательные файлы рядом с ним. Тесты создают отдельные временные каталоги и удаляют их после завершения.

Реализации учебные: ожидают корректные числовые данные; предусмотрены базовые проверки открытия файлов. Временные файлы алгоритмов удаляются при нормальном завершении. При сбое записи исходные данные не восстанавливаются автоматически.

## Демонстрация работы с файлами

Назначьте SortingDemo запускаемым проектом и нажмите Ctrl + F5. Выберите одну из трёх внешних сортировок. Программа покажет путь к input.txt, предложит изменить числа и нажать Enter, затем выведет данные до и после сортировки.

Папка demo_files создаётся относительно текущего рабочего каталога. В ней before.txt хранит исходные числа, а input.txt — результат. Папка исключена из Git. Чтобы задавать постоянный рабочий каталог при запуске из Visual Studio, в свойствах SortingDemo откройте «Отладка → Рабочий каталог» и укажите $(ProjectDir).

Для просмотра промежуточных файлов запустите программу через F5 с точкой останова перед слиянием внутри выбранного алгоритма; после завершения временные файлы удаляются.
